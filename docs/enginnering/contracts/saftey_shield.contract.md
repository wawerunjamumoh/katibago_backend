# Relationships

Now let's reason.

Should SafetyShield belong to Feedback?

No.

Feedback is about a specific choice.

SafetyShield applies regardless of which option the learner selected.

---

Should it belong to CitizenExplanation?

Closer...

But still no.

CitizenExplanation explains the law.

SafetyShield explains **what to do**.

---

Should it belong to Article?

I say **yes**.
