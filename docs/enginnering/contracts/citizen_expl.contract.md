# Citizen explanation format

Every `CitizenExplanation` should consistently answer these four questions, even though they're stored in a single `explanation` field:

1. **What right or duty does this article establish?**
2. **Why does this protection exist?**
3. **How would an ordinary Kenyan encounter this in daily life?**
4. **What is a common misconception or limitation?**
